In one visually verified recovery, the recent frames showed the requested hardware against the wrong game. Older frames displayed the correct game and setting. That case motivates a test of target-specific evidence selection. It was reviewed during design and is excluded from this evaluation. ## Frozen design

- The manifest fixes 60 clips and 300 questions across four StreamingBench archive shards. Clip IDs from the prior targeted review and the 30-clip confirmation are excluded. Selection uses a deterministic metadata rank, with text-rich quotas for three shards. The published reproduction already covers these clips in aggregate, and original source overlap remains unverified. Results apply to this within-benchmark sample.
- Sample on the same 0.5 FPS grid with the latest source frame at or before each grid point. Split up to 20 causal samples into full, disjoint four-frame windows working backward from the query. Earlier questions with a single available window use recent frames in every arm. The 269 questions with a choice of at least two full windows form the primary cohort.
- The same frozen LLaVA-OneVision-Qwen2-0.5B model estimates question-to-window relevance, target identifiability, and whether the requested evidence is shown for that exact target. The score averages the signed Yes-minus-No logit difference across the two A/B label orders. Routing sees only the question and one candidate at a time. Every scored window has the same number of visual tokens and identical compact answer positions.
- The six fixed selectors are recent, previous, global relevance, target only, mean of target and binding, and minimum of target and binding. Ties go to the newest window. A single answer per unique candidate is replayed across all selectors choosing it. The all-window correct-answer oracle uses gold only afterward to measure headroom under the candidate policy.
- The sole primary contrast is conjunction minus mean. Report paired wins/losses, window switches, a question-weighted accuracy difference and a video-resampled percentile interval (10,000 draws), plus leave-one-video sensitivity. Baseline contrasts and the text-rich slice are secondary. Method timings sum isolated builds, applicable probes and one answer. End-to-end latency, upstream feature memory and streaming speed remain unmeasured.

## Decision after the first complete run

1. Advance to external validation if the primary interval is above zero, the point estimate also beats recent-only and global relevance, and the blinded review supports better target binding. Inspect the cost before committing to a deployment claim. The initial run uses one backbone and one benchmark.
2. If the interval includes zero, inspect how often mean and conjunction actually select different frames and how much oracle headroom remains. Large oracle headroom with weak selectors supports work on the verifier. Small oracle headroom points to the candidate pool or answering model. Preserve this run as the frozen test and use fresh data for any revised rule.
3. Two reviewers should independently label randomized window pairs as showing the requested evidence for the exact target, showing a distractor or partial match, or uncertain. Complete those labels before inspecting the key. Keep agreement, adjudication, and scoring anomalies in the evidence. Correct answers alone cannot establish ground truth about where support appeared.
4. If the method advances, freeze an approved external streaming benchmark, a stronger second backbone, a faithful published comparator, and end-to-end latency and memory measures before the next test. Do this before drafting a positive method claim for Neurocomputing.
