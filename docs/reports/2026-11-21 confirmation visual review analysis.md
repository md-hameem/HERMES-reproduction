# Visual evidence in the 12 confirmation disagreements

The uploaded review contains **35 contact sheets and 231 frame slots** from all 12 primary disagreements across 10 clips. The audit matches the frame map and outcome key to the completed confirmation run and verifies the notebook and ZIP hashes. It validates the saved metadata and images. The source videos are outside this local audit.

The uploaded notes were blank. One analyst reviewed all sheets and recorded provisional observations while keeping the packaged outcome key separate, then joined the labels to the saved answers. Prior project discussion exposed some outcomes. This is a single-reader diagnostic review of selected disagreements and does not estimate the prevalence of these patterns.

Recent frames contained usable evidence in **nine of the 12** reviewed cases. That includes three all-history recoveries. The other recovery is the clearest older-evidence case, but small text still needs an original-resolution check.

| Case | What the sheets show | Why it matters |
|---|---|---|
| 112/q3 | The older window shows the *God of War 4* chart around samples 272–273. Its relevant green bar appears to read 101 FPS. The recent window shows *Cyberpunk 2077*, including an 87 FPS bar on a different series. | A generic preference for recent frames can miss an older chart that matches the named target. Confirm the exact hardware line and number at original resolution. |
| 109/q3 | The recent BIOS screen at sample 300 shows **1.400 V**. Older frames show unrelated benchmark charts and the presenter. | All-history answered correctly even though the setting is visible in the recent input. This is a recovery with recent evidence available. |
| 118/q1 and 146/q2 | The latest frames show a Cooler Master badge and a barbell, respectively. In 146/q2 the older frames also show bench pressing. | A contextual run can regress despite visible recent evidence. The review cannot identify which internal change caused that regression. |
| 133/q2 and 133/q3 | Both questions use the same frame slots at 420 s. The painter is clearly adding background color, while the exact support surface is harder to identify. | The effects can depend on the question, even with identical visual inputs. |
| 121/q3 | The V-Ray chart is in the recent window. The thumbnail value for RTX 3080 looks like **2341**, while the benchmark option is **2314**. The **3972** label is on the RTX 4080 row. | Possible annotation or transcription disagreement. Leave it unresolved until the original frame is checked. |

The next inexpensive check is to export originals for **112/q3 sample 273** and **121/q3 sample 278**. Keep the other uncertain case, 133/q2, as uncertain if a clearer view still does not identify the surface. Samples 109 and 112 also appear to share a presenter and studio, reinforcing the need to check source groups in later evaluation.

The most specific hypothesis worth developing is **target grounding across time**. Start with the recent view and test whether it contains the entity or event named in the question. In the chart example, the target game and hardware configuration must match before using a numeric value from either window. This describes a possible intervention, not demonstrated routing performance. Compare any implementation against compact recent-four and a simple older-frame retrieval control with matched inputs and costs. Choose new source groups for evaluation because these 12 questions informed the hypothesis.
