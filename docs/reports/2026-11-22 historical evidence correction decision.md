# Test earlier evidence before changing answers

The next candidate is **recent-first correction with answer-specific visual evidence**. Start with the answer from recent frames, then test whether earlier footage supports a specific competing option at the time the question asks about. The existing run gives this idea room to succeed. An older-only window yielded a correct answer on 33 questions when recent did not, while the previous selector overturned 23 correct recent answers. Start with a blinded review and a small controlled test on cached clips. Originality and an accuracy gain are still open. [Target-binding analysis](<2026-11-22 target binding analysis.md>)

## The saved verifier gives little reason to tune its threshold

On the 269 eligible questions, the minimum rule scored 147 correct, the mean rule scored 152, and recent-only scored 156. The minimum score equaled the binding score in **1,262 of 1,264 windows**, and ranking by binding alone made the exact same choice for every question. The binding prompt gave opposite signs under swapped A/B labels in **815 windows**. Replaying a gate that opens only when recent is negative and an older window scores nonnegative yielded seven switches with zero corrections or regressions. This rules out that specific gate as a useful next implementation. [Reproducible CPU replay](../../results/target_binding_2026-11-22/verifier_replay.json) · [Replay script](../../scripts/prepare_target_binding_review.py)

An older-window correct answer can come from actual evidence, priors, or guessing. Two reviewers should independently label the **147 windows across 32 questions from 28 clips** in the prepared worksheet. Record the supported option, whether the exact target and setting are visible, whether the evidence is valid at query time, and any uncertainty. Adjudicate before looking at model predictions, gold choices, or sampling strata. The worksheet deliberately samples eight questions per recent/older correctness stratum. Use it to identify mechanisms. Estimating population prevalence requires a separate sample. Visual-support labels and GPU tests are pending. [Blinded review worksheet](../../results/target_binding_2026-11-22/visual_support_review.csv)

## Fix the recent frames and vary the older evidence

For the mechanism test, use the same four recent frames in every condition. Add two earlier frames with verified, time-valid support in one condition and two naturally occurring wrong-target or wrong-setting frames from the same clip in the other. Match frame count, visual-token budget, age as closely as possible, and answer prompts. Keep a recent-only control and a question-only control. Freeze the answer options and use forced-choice scores with option-order checks. Require repeatable improvement against the matched distractor across source clips. Human-selected frames are privileged diagnostic inputs. The deployable policy must retrieve and verify its own evidence.

If that test supports the mechanism, freeze a separate four-frame-budget comparison of four recent frames, two recent plus two chronological older frames, and two recent plus two frames selected by the proposed policy. Give the learned or tuned selector and its closest comparator identical candidate access and scan budgets. Answer every question and report gains and baseline-correct regressions separately, along with paired source-cluster intervals and end-to-end latency and memory. Stop if the mechanism fails to repeat or a close comparator matches the resulting method. Generalization should use source-disjoint data and a second backbone after the policy is frozen.

## Prior work narrows the contribution

StreamScout already escalates to deeper historical views. FrameBlend already re-prefills selected HERMES cache slots. PACE verifies option-discriminative evidence in longer videos, and MACD uses targeted video counterfactuals for contrastive decoding. Evidence-Calibrated Selective Decoding proposes bounded evidence-based correction for image QA and reports no model-level validation. The open hypothesis here is whether the same causal stream supplies enough time-valid evidence for a competing answer to justify overriding the recent answer under a matched streaming budget. That distinction needs a direct comparison and evidence before it can carry a paper. [StreamScout](https://arxiv.org/abs/2609.00291) · [FrameBlend](https://arxiv.org/html/2610.29229v1#A1.SS3) · [PACE](https://arxiv.org/abs/2608.26355) · [MACD](https://proceedings.mlr.press/v306/xiao26w.html) · [Evidence-Calibrated Selective Decoding](https://arxiv.org/abs/2611.18670)

TwinPast provides a candidate external test with 350 pairs that share recent context but differ in earlier evidence and the correct answer. Keep both branches of each pair together in splits and resampling. Pair accuracy requires both answers to be correct, which makes the benchmark useful for testing sensitivity to historical evidence. [TwinPast v2](https://arxiv.org/abs/2610.41983v2)
