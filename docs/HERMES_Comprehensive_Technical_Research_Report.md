# Report B: Individual Paper Exhaustive Technical Reviews

## Paper 1: HERMES: KV Cache as Hierarchical Memory for Efficient Streaming Video Understanding

* **Research Context & Problem Formulation:** Real-time processing of unbounded streaming video presents a computational barrier for Multimodal Large Language Models (MLLMs). Standard implementations incur linear KV-cache memory growth ($\mathcal{O}(T)$), causing Out-Of-Memory (OOM) failures or latency escalation. Conventional offline KV-cache compression techniques rely on query-guided attention scoring; however, in continuous streaming, user queries arrive unpredictably after video chunks have already passed. Caching models that offload tensors to external CPU storage (e.g., ReKV) induce retrieval latencies exceeding 0.60 seconds, which disrupts interactive real-time dialogue.
* **Core Architectural Framework:** HERMES is a training-free, query-agnostic inference framework that structures the internal transformer KV-cache into a three-tiered hierarchical memory system based on layer depth:
1. *Sensory Memory (Shallow Layers, e.g., Layers 0–5):* Governed by recency bias, preserving high-fidelity spatial representations of newly arriving video chunks while evicting older frames.
2. *Working Memory (Middle Layers, e.g., Layers 6–20):* Operates via a hybrid retention policy that balances temporal recency with evolving cross-frame semantics.
3. *Long-Term Memory (Deep Layers, e.g., Layers 21–31):* Retains periodic, rhythmic "anchor tokens" that capture global scene semantics across the video stream.

* **Mechanistic Foundations:** Mechanistic attention analyses across transformer layers show that query-dependent attention similarity drops to $\sim 0.4$ in deeper layers, while attention patterns naturally resolve into sparse periodic spikes corresponding to frame token boundaries (e.g., 196 tokens per patch grid). HERMES exploits this intrinsic stratification to eliminate query-dependent caching.
* **Key Components & Mathematical Formulations:**
* *Cross-Layer Memory Smoothing:* Prevents representational fragmentation caused by independent layer-wise token eviction. Semantic retention decisions in deep layers propagate backward through the network using smoothing coefficients:

$$\lambda_l = \begin{cases} 0.1, & \text{if } l \in L_{shallow} \\ 0.3, & \text{if } l \in L_{middle} \\ 0.4, & \text{if } l \in L_{deep} \end{cases}$$

* *Summary Token Aggregation:* Discarded tokens in deep layers are not purged; their value vectors are mean-pooled into a compact summary token ($k_{sum}, v_{sum}$) to preserve background context:

$$v_{sum}^{(l)} = \frac{1}{\mid \mathcal{E}_l\mid} \sum_{i \in \mathcal{E}_l} v_i^{(l)}$$

* *M-RoPE Positional Re-Indexing:* When intermediate tokens are pruned, 3D rotary positional embeddings (temporal, height, width coordinates) are re-mapped into a contiguous index space to prevent rotational phase drift.

* **Experimental Findings:** Evaluated on an NVIDIA A800 (80GB) GPU using LLaVA-OneVision-7B and Qwen2.5-VL-7B backbones. HERMES maintains a constant Time to First Token (TTFT < 30 ms) across $10^4$ continuous frames, delivering a 10× latency reduction compared to retrieval-based systems. It prunes up to 68% of visual tokens while yielding an absolute accuracy gain of up to 11.4% on streaming benchmarks over uncompressed baselines.

## Paper 2: InfiniPot: Context-Aware Pruning for Long-Context LLMs with Multi-Hop Reasoning

* **Research Context & Problem Formulation:** As LLMs process long sequences across single-document QA, multi-document QA, and summarization, maintaining full KV-caches on resource-constrained hardware becomes computationally prohibitive. Existing token pruning techniques (such as StreamingLLM, H2O, and SnapKV) rely heavily on static Sliding Window Attention (SWA) or isolated attention scoring, which frequently discard critical intermediate facts needed for multi-hop reasoning.

* **Core Architectural Framework:** InfiniPot introduces Context-Aware Pruning (CaP), dividing context retention into two complementary mechanisms:

1. *CaP-G (Global Context Scoring):* Measures token importance across the full sequence to retain globally prominent entities.

2. *CaP-Q (Query-Aware Context Scoring):* Dynamically adjusts attention retention masks based on the specific query prompt.

* **Mechanistic Findings:**
* *Layer Hit-Rate Dynamics:* In shallow layers (0–5), SWA and CaP demonstrate comparable token retention profiles ($\sim 35\text{--}42\%$ hit rates). In deeper layers (10–31), SWA performance declines to $\lt  18\%$, whereas CaP-Q maintains a 35–50% hit rate, showing that deeper layers require query-driven token selection rather than static sliding windows.

* *Layer Overlap Consistency:* Overlap rates between sequential contexts remain high ($\sim 70\text{--}88\%$) in upper layers, demonstrating that token utility stabilizes deeper in the network.

* **Empirical Evidence on Multi-Hop Reasoning:**
* *LongBench Comprehensive Evaluation:* Under a constrained 4K memory budget on LLaMA-3-8B-Instruct, InfiniPot matches or exceeds full-context models across 16 tasks. On HotpotQA multi-hop reasoning, InfiniPot scores 49.75%, whereas competing methods (e.g., SirLLM) fail by evicting critical bridging context (such as Passage 4 identifying Xcel Energy as a utility holding company), causing models to output "None of the above".

## Paper 3: StreamFlow: Dynamics-Aware GOP Memory Flows for Streaming MLLMs

* **Research Context & Problem Formulation:** Streaming video understanding suffers from two primary computational inefficiencies:
1. *Encoding Redundancy:* Vision Encoders (ViT) redundantly re-encode static background patches across consecutive streaming frames.
2. *Autoregressive Decoding Drift:* As language models generate long multi-token outputs, self-attention shifts toward newly generated text, weakening attention to historical visual tokens (Visual Attention Drift).

* **Core Architectural Framework:** StreamFlow combines dynamic visual compression with online attention tracking:
* *Dynamics-Aware GOP Partitioning:* Video frames are organized into Groups of Pictures (GOPs), consisting of an anchor I-frame and subsequent P-frames. Temporal pixel residuals ($\mid X_{g, f} - X_{g, 0}\mid$) filter out static background regions, restricting ViT encoding to dynamic patches and reducing visual tokens prior to cache ingestion.
* *Visual Attention Score (VAS) Monitoring:* During generation, the model tracks visual attention across all decoding heads:

$$VAS_t = \frac{1}{L \cdot H} \sum_{l=1}^{L} \sum_{h=1}^{H} \sum_{i \in \mathcal{V}} A_{t, i}^{(l, h)}$$

When $VAS_t$ drops below threshold $\tau$ (indicating that generation is drifting toward language priors), StreamFlow retrieves historical visual latents from a mid-term GOP buffer and injects them into the decoding stream.

* **Experimental Results:** Implemented on Qwen3.5-9B, StreamFlow achieves 67.73% accuracy on StreamingBench (+4.63% over LiveVLM-7B) and 81.55% on the RTVU benchmark, alongside a 21.1% peak GPU memory reduction and 50.4% end-to-end latency reduction.

# Report C: Deep Mechanistic Analysis of HERMES

## 3.1 Layer-Wise Attention Dynamics

HERMES is based on the finding that attention allocation in Vision-Language Models stratifies naturally across layer depth:

* **Shallow Layers (Sensory Memory, Layers 0–5):** The attention matrix $A^{(l)}$ exhibits strong recency bias. Given input tokens $\{x_1, x_2, \dots, x_T\}$, query tokens at step $T$ allocate over 80% of attention mass to tokens within the most recent chunk $[T - \Delta, T]$. These layers function as a sensory buffer, capturing high-frequency spatial features such as edges, textures, and immediate motion. Older tokens in these layers can be pruned with minimal impact on higher-order semantic reasoning.
* **Middle Layers (Working Memory, Layers 6–20):** Attention expands across the temporal window. The recency bias moderates, with attention distributed across recent tokens and intermediate semantic representations. These layers track ongoing state changes and multi-frame actions.
* **Deep Layers (Long-Term Memory, Layers 21–31):** Recency bias disappears entirely. Attention becomes sparse and rhythmic, forming distinct periodic peaks at frame patch boundaries (e.g., every 196 tokens). These peaks identify "anchor tokens"—specific visual patches (such as interacting objects or salient agents) that capture the core semantic content of an entire frame.

## 3.2 Hierarchical KV-Cache Management Formulation

HERMES calculates a layer-dependent token retention score $S_i^{(l)}$ for each token $i$ at layer $l$:

$$S_i^{(l)} = \alpha_l \cdot \mathcal{R}_i + (1 - \alpha_l) \cdot \mathcal{A}_i^{(l)}$$

where:

* $\mathcal{R}_i = \exp(-\gamma \cdot (T - t_i))$ represents the exponential recency score, governed by decay rate $\gamma$ and temporal distance $(T - t_i)$.
* $\mathcal{A}_i^{(l)} = \frac{1}{\mid Q\mid} \sum_{q \in Q} A_{q, i}^{(l)}$ is the accumulated attention score allocated to token $i$ across guidance queries $Q$ at layer $l$.
* $\alpha_l \in [0, 1]$ is a layer-dependent weighting parameter configured such that $\alpha_l \to 1.0$ in shallow layers (prioritizing recency) and $\alpha_l \to 0.0$ in deep layers (prioritizing attention peaks).

Tokens are ranked by $S_i^{(l)}$ within each layer, and the lowest-scoring tokens are evicted once the cache exceeds its assigned memory budget $B_l$.

## 3.3 Cross-Layer Memory Smoothing

Evicting tokens independently across layers can disrupt feature representations during subsequent forward passes. If token $i$ is retained in Layer 26 as an anchor but pruned in Layer 8, the upper layer loses its lower-level feature pathway.

HERMES resolves this by propagating importance scores backward through the network:

$$\tilde{S}_i^{(l)} = S_i^{(l)} + \sum_{k > l} \lambda_k \cdot \tilde{S}_i^{(k)}$$

Applying smoothing coefficients ($\lambda_{shallow}=0.1$, $\lambda_{middle}=0.3$, $\lambda_{deep}=0.4$) ensures that tokens flagged as critical anchors in deep layers are protected from eviction in shallow sensory layers.

## 3.4 Multi-Modal Rotary Position Embedding (M-RoPE) Re-Indexing

In standard transformers, Rotary Position Embeddings (RoPE) encode token positions by rotating query and key vectors in the complex plane:

$$\mathbf{R}_{\Theta, m}^{d} \mathbf{k}_m = \text{diag}\left(R_{\theta_1, m}, R_{\theta_2, m}, \dots, R_{\theta_{d/2}, m}\right) \mathbf{k}_m$$

In models using 3D M-RoPE (such as Qwen2.5-VL), position indices split into three functional coordinates: temporal ($m_t$), vertical spatial ($m_h$), and horizontal spatial ($m_w$).

Pruning intermediate tokens creates non-contiguous gaps in the index sequence:

$$\mathcal{M}_{original} = [1, 2, \dots, 50, 150, 151, \dots]$$

These gaps introduce phase shifts that distort the relative attention distances computed for newly arriving tokens:

$$\langle \mathbf{R}_{m_1} \mathbf{q}, \mathbf{R}_{m_2} \mathbf{k} \rangle = \mathbf{q}^\top \mathbf{R}_{m_2 - m_1} \mathbf{k}$$

HERMES counteracts this by applying a bijective re-indexing map $\phi: \mathcal{M}_{retained} \to [1, \mid \mathcal{M}_{retained}\mid]$:

$$\tilde{m}_i = \phi(m_i) = \text{rank}(m_i \in \mathcal{M}_{retained})$$

This re-indexing preserves contiguous index sequences, maintaining positional consistency during generation.

## 3.5 Summary Token Aggregation

To prevent the loss of ambient background details when non-anchor tokens are evicted in deep layers, HERMES pools their key and value representations into a single Summary Token ($k_{sum}, v_{sum}$):

$$k_{sum}^{(l)} = \frac{1}{\mid \mathcal{E}_l\mid} \sum_{j \in \mathcal{E}_l} k_j^{(l)}, \quad v_{sum}^{(l)} = \frac{1}{\mid \mathcal{E}_l\mid} \sum_{j \in \mathcal{E}_l} v_j^{(l)}$$

The summary token is appended to the layer's KV-cache, ensuring that cumulative background context remains accessible during self-attention:

$$K_{compressed}^{(l)} = \left[ K_{retained}^{(l)} \,\Vert{}\, k_{sum}^{(l)} \right], \quad V_{compressed}^{(l)} = \left[ V_{retained}^{(l)} \,\Vert{}\, v_{sum}^{(l)} \right]$$

# Report F: Critical Research Gap Analysis

## 1. Retention of Fine-Grained Micro-Events

* **The Problem:** Deep-layer attention in MLLMs naturally concentrates on visually prominent objects and primary actors. Minor, transient visual events (such as a subject briefly setting down a set of keys) often fail to trigger attention peaks, leading to aggressive pruning in long-term memory.
* **Current State:** Partially addressed. HERMES uses summary token aggregation ($k_{sum}, v_{sum}$) to preserve general background representations, but individual micro-events cannot be precisely recovered from the pooled state.
* **Research Opportunity:** Developing dual-path memory systems that combine low-level motion anomaly detectors with deep semantic anchor extraction.

## 2. Autoregressive Visual Attention Drift

* **The Problem:** During long multi-token generation, MLLM self-attention tends to concentrate on previously generated text tokens, diminishing attention to visual tokens in the cache and increasing hallucination risks.
* **Current State:** StreamFlow addresses this by tracking Visual Attention Scores ($VAS < \tau$) and injecting external GOP latents; however, this requires trained neural compressors and alters sequence lengths mid-generation.
* **Research Opportunity:** Designing training-free decoding hooks that dynamically adjust attention logits for cached visual anchor tokens when visual attention drops.

## 3. Audio-Visual Temporal Synchronization in Continuous Streams

* **The Problem:** Streaming benchmarks (such as StreamingBench) show consistent performance drops when models must correlate transient audio signals (e.g., an off-screen sound) with visual events. Existing KV-cache management techniques evaluate visual attention independently of incoming audio streams.
* **Current State:** Unresolved. Cache eviction remains primarily vision-centric.
* **Research Opportunity:** Multi-modal cross-attention gating, where audio event detectors modulate visual token retention in the working memory cache.

# Report G: Novelty Verification and Overlap Analysis

## Proposed Direction: Training-Free Entropy-Guided Dynamic Memory Injection (EDMI)

* **Core Concept:** A training-free inference framework that links the hierarchical KV-cache organization of HERMES with real-time visual attention monitoring during decoding. When the Visual Attention Score drops ($VAS_t < \tau$), the model applies a dynamic logit adjustment to historical anchor tokens and summary tokens ($k_{sum}, v_{sum}$) within the existing cache, counteracting attention drift without external retrieval or model fine-tuning.
* **Overlap Analysis:**
* *HERMES (Zhang et al., 2026):* Establishes layer-wise hierarchical KV-cache partitioning, periodic anchor selection, and summary pooling during ingestion. It does not monitor or adjust attention during autoregressive generation.
* *StreamFlow (2026):* Tracks visual attention scores ($VAS < \tau$) to trigger retrieval, but relies on an external GOP buffer and a trained neural compressor $C_\phi$.
* InfiniPot (Qualcomm, 2024): Implements Context-Aware Pruning for long-context question answering, but operates statically rather than during streaming decoding.

* **Novelty Classification:** **Potentially Unexplored within Uploaded Literature.** EDMI provides a fully training-free, zero-retrieval mechanism to prevent visual attention drift using summary states already present in the KV-cache.

# Report H: Implementation and Experimental Roadmap

## 1. Mathematical Formulation

During autoregressive decoding at step $t$, the system computes the Visual Attention Score ($VAS_t$) across all layers $L$ and attention heads $H$:

$$VAS_t = \frac{1}{L \cdot H} \sum_{l=1}^{L} \sum_{h=1}^{H} \sum_{i \in \mathcal{V}} A_{t, i}^{(l, h)}$$

where $\mathcal{V}$ represents the set of visual anchor tokens and summary tokens ($k_{sum}$) in the cache.

If $VAS_t < \tau$, pre-softmax attention logits $S_{t, i}^{(l, h)} = \frac{\mathbf{q}_t^{(l, h)} (\mathbf{k}_i^{(l, h)})^\top}{\sqrt{d_k}}$ are adjusted prior to generating the next token:

$$\tilde{S}_{t, i}^{(l, h)} = \begin{cases} S_{t, i}^{(l, h)} + \alpha \cdot (\tau - VAS_t) \cdot \Omega_i, & \text{if } i \in \mathcal{V} \text{ and } VAS_t < \tau \\ S_{t, i}^{(l, h)}, & \text{otherwise} \end{cases}$$

where $\Omega_i \in [0, 1]$ represents the normalized historical importance score of token $i$, $\tau \in [0.15, 0.25]$ is the activation threshold, and $\alpha$ is a scaling hyperparameter.

## 2. Algorithmic Implementation (PyTorch Attention Hook)

```python
import torch
import torch.nn.functional as F

class StreamingEDMIHook:
    """
    Entropy-Guided Dynamic Memory Injection (EDMI) Hook.
    Intercepts attention computation during decoding to prevent visual drift.
    """
    def __init__(self, tau: float = 0.20, alpha: float = 1.8):
        self.tau = tau
        self.alpha = alpha
        self.visual_indices = set()
        self.anchor_indices = set()

    def set_cache_indices(self, visual_idx: list, anchor_idx: list):
        self.visual_indices = set(visual_idx)
        self.anchor_indices = set(anchor_idx)

    def __call__(self, q: torch.Tensor, k: torch.Tensor, v: torch.Tensor, layer_idx: int):
        """
        q: [Batch, Heads, 1, Dim]
        k: [Batch, Heads, Seq_Len, Dim]
        v: [Batch, Heads, Seq_Len, Dim]
        """
        B, H, _, D = q.shape
        S = k.shape[2]
        scale = 1.0 / (D ** 0.5)

        # 1. Compute standard attention logits
        logits = torch.matmul(q, k.transpose(-1, -2)) * scale  # [B, H, 1, S]
        attn_weights = F.softmax(logits, dim=-1)

        # 2. Evaluate Visual Attention Score (VAS)
        vis_mask = torch.zeros(S, dtype=torch.bool, device=q.device)
        for idx in self.visual_indices:
            if idx < S:
                vis_mask[idx] = True

        vas_score = attn_weights[:, :, :, vis_mask].sum(dim=-1).mean().item()

        # 3. Dynamic Attention Logit Injection if VAS drops below tau
        if vas_score < self.tau:
            injection_magnitude = self.alpha * (self.tau - vas_score)
            for idx in self.anchor_indices:
                if idx < S:
                    logits[:, :, :, idx] += injection_magnitude
            # Recompute attention weights with boosted logits
            attn_weights = F.softmax(logits, dim=-1)

        output = torch.matmul(attn_weights, v)
        return output

```
