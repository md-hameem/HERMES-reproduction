# Repository research documentation

After every completed analysis, code change, experiment, or research decision, append an entry to [docs/research_log.md](docs/research_log.md) and synchronize [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md).

Each entry must record the date, trigger/objective, files or scripts created or modified, verified commands and results tagged [VERIFIED], open hypotheses and blockers tagged [HYPOTHESIS], and the next gate or action. Record observed evidence as facts. Append a new dated report for a major milestone and preserve prior dated reports.
